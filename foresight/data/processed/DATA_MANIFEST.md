# Data Manifest — `data/processed/`

This directory contains all pipeline-generated datasets, organized by purpose.

---

## 📁 `cleaned/` — Pipeline Intermediate Tables
Individual tables after cleaning (dedup, imputation, outlier capping, type fixes).
Generated by: `python -m src.pipeline`

| File | Rows | Description |
|------|------|-------------|
| `sales_daily_clean.csv` | ~73K | Daily sales per SKU — cleaned, deduped, outliers capped |
| `sku_master_clean.csv` | ~200 | SKU catalog — standardized categories, fixed dtypes |
| `calendar_clean.csv` | ~730 | Calendar with holidays, seasons, promo events |
| `inventory_clean.csv` | ~14K | Inventory snapshots — imputed lead times, non-negative |
| `cleaning_log.csv` | varies | Every cleaning decision with rationale (audit trail) |

---

## 📁 `features/` — Analysis-Ready & Feature-Engineered Datasets
Merged and enriched datasets used by models.

| File | Generated By | Description |
|------|-------------|-------------|
| `analysis_ready.csv` | `pipeline.py` | All 4 tables merged into one master dataset (20 columns) |
| `featured_dataset.csv` | `features.py` | Weekly aggregated + 42 engineered features (lags, rolling stats, calendar encoding, price features, demand velocity) |

---

## 📁 `forecasts/` — Model Predictions & Comparison
Output from demand forecasting models.
Generated by: `python -m src.baseline` and `python -m src.forecast`

| File | Generated By | Description |
|------|-------------|-------------|
| `baseline_results.csv` | `baseline.py` | Seasonal-naive forecast (same week last year) vs actuals |
| `lgbm_results.csv` | `forecast.py` | LightGBM predictions with 80% confidence intervals |
| `model_comparison.csv` | `forecast.py` | WAPE comparison across all models |
| `feature_importance.csv` | `forecast.py` | Top feature importances from LightGBM model |

---

## 📁 `dashboard/` — Data Consumed by the UI
Risk scores and action items displayed in the Streamlit dashboard.
Generated by: `python -m src.risk`

| File | Description |
|------|-------------|
| `risk_scored.csv` | Stockout/overstock risk per SKU, quadrant assignment, recommended action, ₹ at stake |
